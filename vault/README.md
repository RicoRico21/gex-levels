# The vault

This is Jarvis's memory. Every file is plain markdown — open it in Obsidian,
edit it by hand, sync it to your phone, or delete it. Nothing is hidden in a
database.

- `inbox/` — the running log. Things Jarvis captured as they came up.
- `daily/` — one note per day: the plan and what happened.
- `clients/` — one note per client. Jarvis reads these before writing to them.
- `content/` — `voice.md` (your brand voice) and the content pipeline.
- `trading/` — the trade journal: ideas, theses, and outcomes.

The contents are gitignored by default, since they're personal. If you want
them version-controlled, remove the `vault/**` lines from `.gitignore`.
